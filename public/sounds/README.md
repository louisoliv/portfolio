# Sons du cockpit

Déposer ici les fichiers, avec exactement ces noms :

| Fichier            | Quand il est joué                                                  |
|--------------------|--------------------------------------------------------------------|
| `alert.mp3`        | clic sur le bouton d'alerte de la console                          |
| `hero-show.wav`    | la carte de présentation apparaît                                  |
| `back.wav`         | la carte de présentation disparaît, et retour à la vue d'ensemble  |
| `section-open.wav` | ouverture d'une section (panneau ou bouton)                        |

Un fichier absent est simplement ignoré (pas de son, pas d'erreur).
